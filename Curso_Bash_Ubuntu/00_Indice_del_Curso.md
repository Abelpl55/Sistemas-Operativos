# Curso de Bash Scripting en Ubuntu

## Para estudiantes de Sistemas Operativos - Nivel Ingenieria

Este curso esta disenado para llevarte desde los fundamentos de Linux y la terminal
hasta la capacidad de completar un proyecto completo de administracion de servidores
con Bash scripting.

---

## Requisitos Previos

- Ubuntu 20.04 o superior (o WSL2 en Windows)
- Acceso a una terminal (Ctrl+Alt+T en Ubuntu)
- Editor de texto (nano, vim, o VS Code)
- Ganas de aprender

## Como usar este curso

1. Sigue las lecciones en orden (01 a 15)
2. Ejecuta todos los ejemplos en tu terminal
3. Completa los ejercicios al final de cada leccion
4. La leccion 15 te guia paso a paso en el proyecto final

## Convenciones

- `$ comando` indica un comando que debes escribir en la terminal
- Los bloques de codigo muestran scripts completos o fragmentos
- **Negrita** indica conceptos clave
- Los ejercicios marcados con [PRACTICA] son para que los resuelvas
